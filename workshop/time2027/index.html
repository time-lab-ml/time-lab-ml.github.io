Overview

Welcome to TIME 2027 (3rd International Workshop on Transformative Insights in Multi-faceted Evaluation), held in conjunction with The Web Conference 2027.

As foundation models, multimodal AI, generative systems, retrieval-augmented generation (RAG), and AI agents become deeply embedded across the Web, powering search, recommendation, content creation, and autonomous workflows, their capabilities and risks can no longer be captured by conventional task-specific accuracy metrics alone. Operating across heterogeneous data, external tools, and dynamic user environments introduces critical challenges such as hallucination, bias, privacy leakage, and poor calibration.

Building on the successful editions of TIME 2025 and TIME 2026, this full-day workshop brings together researchers and practitioners to address a central question for the next generation of Web AI: how should we evaluate systems whose capabilities, behaviours, and risks extend far beyond conventional task-level performance? Through invited talks, paper presentations, posters, an interactive panel, and breakout discussions, TIME 2027 provides a collaborative forum to examine what should be evaluated, how it should be measured, and how evaluation insights translate into trustworthy, real-world Web systems.

Workshop Objectives

TIME 2027 aims to advance the practice of evaluating modern Web AI systems through four core objectives:

  1. Advance Multi-faceted Evaluation: Develop evaluation methodologies that move beyond single-task accuracy to jointly assess capability, reliability, robustness, safety, fairness, interpretability, uncertainty, efficiency, and real-world utility.
  2. Evaluate Emerging Web AI Systems: Identify new evaluation challenges arising from foundation models, multimodal and generative AI, retrieval-augmented systems, and agentic Web applications operating across dynamic environments.
  3. Promote Rigorous and Actionable Evaluation: Encourage reproducible benchmarks, datasets, protocols, and practical tools that provide meaningful evidence and actionable insights beyond headline performance numbers.
  4. Build an Interdisciplinary Community: Connect academic researchers, industry practitioners, and early-career researchers across Web mining, information retrieval, multimodal learning, security, privacy, and human-centred AI to establish shared priorities for trustworthy Web AI.
